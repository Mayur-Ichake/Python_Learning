				Variables
.........................................................

> Variables are the named memory blocks which are used to store some value.

Syntax : variable = value

Steps of Memory Allocation :
.................

Step - 1: When the user assigns a value to a variablke,  the memory is divided conceptually into two parts :
	
	1. Variable Space (Stack)
	2. Value Space (Heap)

Step - 2: First, the value / objects  is stored in  the heap memory by allocating a memory block. Once the value is stored , Python internally creates a reference address for that memory location.

Step - 3: The generated reference  address is stored  in the stack memory and is assigned to the respective variable name.

So , the variable doesn't directly store the value; it store the reference to the value stored in heap space.

Step - 4: When the user calls or accesses a variable, Python first searches for the variables in the stack memory.

If variable is found, Python retrieves the reference address stored in it, then follows that reference to the heap memory to access the actual value.

Step - 5: If the variable is not found in stack memory, Python will raise an error.

This means, the variable is not created in the program.


Reference Address : 
> It is an address where value / variable are represented.
> It is a hexadecimal number i.e. a 16 digit number. Hence, it will always written as "0x" (0x represents any random numbers).

> To see the reference address, we will be using an inbuolt function i.e. id() function.

id() function : It is an inbuilt function which is used to point the reference address of any variable or value.

Syntax : id(variable / value)


Overriding : Overriding means the situation where a new value replaces an existing value of same variable.

> In simple words, when you assign a new value to something that already has a value, the old value is overridden (replaced).

Ques. Why tuple is faster than list ?
Ans.
Tuples are faster than lists because they are fixed and cannot be changed. Python does not need extra work to add, remove, or modify elements in a tuple. Lists are flexible, so Python keeps extra space and checks for changes, which makes lists slightly slower compared to tuples.






		Set (set)
...............................................

> A set in Python is a homogeneous or heterogeneous collection of data items enclosed in curly braces ({}).

> Set is an unordered collection of unique elements i.e. a set must be  having only unique values and duplicated values are not allowed in set.

> If we are passing any duplicated value in set, then duplicated values will be removed automatically.

> As set is unordered , so there will not be having any fixed index position for values. So, set doesn't support for indexing.

Syntax :
{value_1, value_2, ......., value_n}

> Set is dynamic in size (which can be modified).

> Set is a mutable datatype, but values inside set must be immutable. It means it allows only immutable values to be stored inside it. Mutable values inside set are strictly prohibited to use.


Ques. Why set doesn't allow to store mutable values ?
Ans. 
> As we know, when it comes to memory allocation of set, values wil;l be stored in hash table, instead of memory layer.

> So, whatever values are stored in hash table, hash table will providehash values for each value stored inside it and we can print the hash values  by using "hash()" inbuilt function.

> But, when it comes to store any mutable value inside hash table, it will not generate hash value for that mutable value, which means hash table will  not accept mutable collections.

> So, that's why we can say set can't allow to store mutable collections inside it.


Syntax for hash() function : hash(immutable_value)

> As set is mutable, we do modification inside a set in following way :

1. Adding new value
2. Removing existing value


1. Adding new value :

add() function : It is an inbuilt function which is used to add a new value at any random position inside set.

Syntax : variable.add(new_value)


2. Removing existing value :
> This method in set is used to remove existing value from a set.
> For removing value, we'll be using two inbuilt functions :

(i) remove() function
(ii) pop() function


(i) remove() function :
> It is an inbuilt function which is used to remove a particular value froma set by using that specific value.

Syntax : variable.remove(value)

(ii) pop() function :
> It is an inbuilt function which is used to remove any random element from the set.
